# Estate Agent Web Application

A responsive, client-side single-page application (SPA) for searching and browsing properties, built with React.js as part of the 5COSC026W Advanced Client-Side Web Development coursework.

## Live Demo & Repository

- **Live Application**: https://estate-agent-dasumeth2003-dasuntha-samarasinghe.vercel.app
- **GitHub Repository**: https://github.com/dasumeth2003/estate-agent

## Project Overview

This application allows users to search for properties using multiple criteria including type, price range, number of bedrooms, postcode area, and date added. Users can view detailed property information, save favorites, and interact with a fully responsive interface.

## Key Features

### Core Functionality
- **Advanced Property Search**: Filter by type, price, bedrooms, postcode, and date
- **Search Results Display**: Clean, attractive property listings with images and details
- **Property Details Page**: Full property information with image gallery and tabs
- **Favorites System**: Add/remove properties with drag-and-drop functionality
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices

### Technical Features
- **React UI Widgets**: Enhanced forms using react-select and react-datepicker
- **Image Gallery**: Interactive gallery with thumbnails using react-image-gallery
- **Tabbed Interface**: Property details organized with react-tabs
- **Drag & Drop**: Favorites management with react-beautiful-dnd
- **Client-Side Security**: Content Security Policy (CSP) implementation
- **Comprehensive Testing**: JEST test suite with 5+ meaningful tests

## Technologies Used

- **React** 18.2.0 - UI framework
- **React Select** 5.8.0 - Enhanced select inputs
- **React DatePicker** 4.21.0 - Date selection widget
- **React Image Gallery** 1.3.0 - Image gallery component
- **React Tabs** 6.0.2 - Tabbed content organization
- **React Beautiful DnD** 13.1.1 - Drag and drop functionality
- **JEST** - Testing framework
- **CSS3** - Styling with Flexbox and Grid
- **HTML5** - Semantic markup
